# hanifu.id

Personal blog of **Hanif Dwy Putra S** — built with [Astro](https://astro.build), powered by the [Fuwari](https://github.com/saicaca/fuwari) template.

[**🖥️ hanifu.id**](https://hanifu.id)

## Stack

- **Framework:** [Astro](https://astro.build) 5
- **UI:** [Svelte](https://svelte.dev) 5 + Astro components
- **Styling:** [Tailwind CSS](https://tailwindcss.com) 3 + [Stylus](https://stylus-lang.com/)
- **Search:** [Pagefind](https://pagefind.app/)
- **Page transitions:** [Swup](https://swup.js.org/)
- **Comments:** [Giscus](https://giscus.app/)
- **Code blocks:** [Expressive Code](https://expressive-code.com/)
- **Math:** KaTeX
- **Deployment:** [Vercel](https://vercel.com/)

## Commands

| Command | Action |
|:--------|:-------|
| `pnpm dev` | Start dev server at `localhost:4321` |
| `pnpm build` | Build for production + Pagefind index |
| `pnpm preview` | Preview production build |
| `pnpm check` | Run Astro type check |
| `pnpm lint` | Lint & format with Biome |
| `pnpm new-post <filename>` | Create a new blog post |
